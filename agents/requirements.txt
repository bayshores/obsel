# Dependencies for the demo agent workers.
#
# Pinned exactly. Two of the traps recorded in docs/environment-findings.md are
# version-dependent and fail silently rather than loudly, so "whatever pip
# resolves today" is not an acceptable answer here.

# The DataHub Python SDK. Used by agents/setup.py to create obsel's tag and the
# demo DataFlow -- entity creation that the MCP surface cannot do -- and by
# agents/graph.py to register tasks. 1.6.0.15 is the version verified against
# GMS v1.5.0.6 on the local quickstart; see docs/environment-findings.md.
acryl-datahub==1.6.0.15

# The model client for the agent workers themselves. obsel's own coordinator
# makes no model calls; only the agents in this directory do.
openai==2.46.0

# Everything else the agents need -- HTTP to obsel, hashing, JSON -- is in the
# standard library on purpose, so an agent joining a swarm needs almost nothing
# installed to talk to the coordinator.
#
# The DataHub MCP server is not installed from here. It is run with uvx and must
# be pinned to ==0.6.0; `@latest` resolves to a read-only 0.4.0 with no write
# tools that ignores TOOLS_IS_MUTATION_ENABLED without warning. See
# docs/environment-findings.md section 2.
